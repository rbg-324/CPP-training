实验1：14个用例的分支切换、运行与截图
在VS Code中打开 D:\workspace\cpp-training，并在PowerShell终端进入该目录。
每个用例分别切换到失败分支和通过分支；切换后重新构建，再只运行当前编号测试。
截图需包括 [ RUN ] TestNN 与 [ FAILED ] 或 [ PASSED ] 汇总。不要把旧截图用于新版本。

用例01：指定初始状态(2,-3,E)，无指令，期望(2,-3,E)
git switch test1-fail
cmake --build build --target training_main
.\build\tests\training_main.exe --gtest_filter=Test01.StoresInitialPose
git switch test1
cmake --build build --target training_main
.\build\tests\training_main.exe --gtest_filter=Test01.StoresInitialPose
