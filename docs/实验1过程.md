# 实验1版本与运行记录

初始工程保留在 `main`。每组用例分别保存在 `testN-fail` 和 `testN` 两个分支，共14组、28个测试分支。测试函数会输出编号、输入或操作以及预期状态。

使用 `MinGW Makefiles` 构建 `training_main` 后，逐一在对应分支运行指定编号的 GoogleTest。28次单项运行均成功构建：14个 `testN-fail` 分支的当前编号测试返回1，14个 `testN` 分支返回0。最终在 `test14` 分支运行完整测试程序，14项均通过，退出码为0。

逐项原始终端截图及退出状态记录在 `docs/screenshots/`；完整实验报告见 `docs/实验1报告.docx`。截图均由实际运行采集，没有复用旧版用例截图。
